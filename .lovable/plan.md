# تطوير لوحة المعلومات: أفضل موظف وأفضل إدارة/قسم ومؤشرات إضافية

توسيع صفحة لوحة المعلومات لتصبح لوحة قيادة حقيقية بدل بطاقات الأعداد فقط، مع لوحة شرف شهرية ومؤشرات تساعد على قراءة الأداء بسرعة.

## ما سيراه المستخدم

### 1. شريط اختيار الفترة
قائمة في أعلى الصفحة (شهري افتراضياً — يومي / أسبوعي / شهري / ربعي) تُحدّث كل مؤشرات اللوحة.

### 2. لوحة الشرف
ثلاث بطاقات بارزة:
- **أفضل موظف**: الاسم، المسمى، القسم، درجة الأداء المركّبة، وشارة التقدير.
- **أفضل إدارة** و**أفضل قسم**: الاسم، عدد الموظفين، الدرجة، ومؤشر تقدّم.
- تحت كل بطاقة سطر يوضّح سبب التصدّر (مثال: «٩٢٪ إنجاز مهام · ٩٦٪ التزام دوام»).

طريقة الاحتساب (نفس منطق التقييم المعتمد في النظام):
`الدرجة = ٥٠٪ إنجاز المهام + ٣٠٪ الالتزام بالدوام + ٢٠٪ الالتزام بالمواعيد (المهام المنجزة قبل الاستحقاق)`
مع اشتراط حد أدنى (مهمة واحدة منجزة على الأقل أو ٣ أيام حضور) حتى لا يتصدّر موظف بلا نشاط.

### 3. جدول ترتيب الأداء
جدول «أفضل ٥ موظفين» و«ترتيب الإدارات/الأقسام» مع أعمدة: الجهة، المهام المنجزة، نسبة الإنجاز، نسبة الالتزام، الدرجة، التقدير.

### 4. مؤشرات إضافية تحسّن قراءة المعلومات
- **بطاقات مؤشرات محسّنة**: بدل الأعداد المجرّدة، تضاف نسبة الالتزام العامة، أيام الغياب اليوم، والمهام المستحقة خلال ٧ أيام.
- **حضور اليوم**: حاضر / متأخر / غائب / إجازة كأشرطة نسبية.
- **توزيع المهام حسب الحالة والأولوية**: أشرطة ملوّنة سريعة القراءة.
- **تنبيهات تحتاج انتباهك**: مهام متأخرة، طلبات إجازة بانتظار اعتمادي، تقييمات بانتظار اعتمادي، وثائق موظفين على وشك الانتهاء (٣٠ يوماً) — كل عنصر قابل للنقر للانتقال إلى صفحته.
- **الموظفون الأكثر تأخراً هذا الشهر** (يظهر للمدير التنفيذي والموارد البشرية والمدراء فقط) لمعالجة الفجوات مبكراً.

### 5. تخصيص حسب الدور
- المدير التنفيذي / الموارد البشرية: كل المؤسسة.
- المدير: نطاق إدارته/قسمه فقط.
- الموظف: بطاقاته الشخصية (ترتيبي، درجتي، مهامي، التزامي) بدل لوحة الشرف العامة.

## التفاصيل التقنية

- **ملف جديد** `src/lib/dashboard-metrics.ts`: دوال نقية تحسب درجة الموظف، تجمّعها على مستوى القسم والإدارة، وترتّب أفضل النتائج. بدون منطق واجهة، وتعيد استخدام `complianceScore` و`countWorkingDays` من `src/lib/attendance.ts` و`gradeFor`/`periodRange` من `src/lib/hr.ts`.
- **مكوّنات جديدة** تحت `src/components/dashboard/`: `TopPerformerCard`، `LeaderboardTable`، `AttentionList`، `AttendanceTodayCard` — للحفاظ على حجم ملف الصفحة صغيراً.
- **تعديل** `src/routes/_authenticated/dashboard.tsx`: استعلام موحّد عبر React Query يجلب ضمن مدى الفترة: `employees`، `departments`، `sections`، `tasks`، `attendance_records`، `leave_requests`، `evaluations`، `employee_documents`، إضافة إلى `work_settings` و`holidays` لحساب أيام العمل.
- تصفية النطاق حسب الدور تتم من `useAuth` (`isDirector` / `isHR` / `isManager` / `employee.department_id`) وتُطبَّق قبل الحساب.
- لا تغييرات في قاعدة البيانات أو سياسات الوصول؛ كل الجداول المطلوبة موجودة وتُقرأ ضمن صلاحيات المستخدم الحالية (سياسات RLS تتكفّل بالتقييد).
- تحديث `head()` للصفحة ليعكس محتوى لوحة القيادة الجديد.
