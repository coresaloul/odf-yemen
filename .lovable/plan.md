# لوحة تقارير الحضور الشهرية

إضافة نوع تقرير ثالث في صفحة التقارير: **تقرير الحضور الشهري** لكل موظف أو قسم أو إدارة، مع نسب الالتزام والتأخير والعائدين من الإذن الساعي، وتصدير Word/PDF بنفس القالب الرسمي الحالي.

## ما سيراه المستخدم

في صفحة «التقارير» يصبح في قائمة نوع التقرير خيار جديد «تقرير الحضور الشهري»، مع نفس مفاتيح النطاق (موظف / قسم / إدارة) والفترة.

عند اختيار الجهة تظهر:

1. **بطاقات مؤشرات عامة**: أيام العمل الرسمية، نسبة الالتزام العامة، أيام الحضور، أيام الغياب، إجمالي دقائق التأخير، عدد العائدين من الإذن الساعي.
2. **جدول تفصيلي لكل موظف** يضم:
   - أيام العمل المطلوبة، أيام الحضور، الغياب، الإجازات، العطل
   - عدد مرات التأخير وإجمالي دقائق التأخير ومتوسط التأخير اليومي
   - دقائق الانصراف المبكر
   - عدد أيام الإذن الساعي ودقائقه، وعدد **العائدين من الإذن** (الأيام التي خرج فيها الموظف بإذن ساعي وسجّل عودة/انصراف بعده في نفس اليوم)
   - نسبة الالتزام (0–100) مع التقدير
3. **جدول تجميعي على مستوى الأقسام/الإدارات** عند اختيار نطاق قسم أو إدارة: نسبة الالتزام لكل قسم، إجمالي التأخير، نسبة الحضور.
4. **جدول أعلى وأدنى التزاماً** (أفضل ٥ وأقل ٥) عندما يكون النطاق قسماً أو إدارة.
5. **جدول أيام التأخير** بالتفصيل للموظف المفرد (التاريخ، الدخول، الخروج، دقائق التأخير، الحالة).

أزرار «تصدير Word» و«تصدير PDF» الحالية تُصدّر التقرير نفسه بكل جداوله وملخص تنفيذي عربي.

## التفاصيل التقنية

- **حساب العائدين من الإذن**: يُحتسب اليوم ضمن «العائدين من الإذن الساعي» عندما تكون `permission_minutes > 0` ويوجد `check_out` مسجّل (أو الحالة `permission` مع تسجيل دخول وخروج) — أي أن الموظف لم يغادر نهائياً بل عاد وأكمل دوامه.
- **مصادر البيانات** (قراءة عبر عميل Supabase من الواجهة كما في بقية الصفحة):
  - `attendance_records` ضمن مدى الفترة للموظفين المستهدفين
  - `attendance_settings` (أيام العمل، بداية/نهاية الدوام، سماح التأخير) و`holidays` لحساب أيام العمل الرسمية
  - `employees` / `departments` / `sections` (مُحمّلة أصلاً في الصفحة)
- **إعادة استخدام** الدوال الموجودة في `src/lib/attendance.ts`: `countWorkingDays`، `isOffDay`، `complianceScore`، `formatMinutes`، `DEFAULT_WORK_SETTINGS`.
- **ملف جديد** `src/lib/attendance-report.ts`: دوال نقية لتجميع صفوف الحضور إلى ملخص لكل موظف (`buildEmployeeAttendanceSummary`) وتجميعها لكل قسم/إدارة (`groupByUnit`)، بدون أي منطق واجهة.
- **تعديل** `src/routes/_authenticated/reports.tsx`:
  - إضافة `attendance` إلى `ReportKind`
  - استعلام React Query جديد لجلب سجلات الحضور والإعدادات والعطل
  - عرض بطاقات وجداول التقرير
  - دالة `buildAttendanceDoc(): ReportDoc` تُغذّي `exportWord` / `exportPdf` القائمين
- لا حاجة لأي تغييرات في قاعدة البيانات أو سياسات الوصول؛ الجداول والصلاحيات المطلوبة موجودة وتُقرأ ضمن صلاحيات المستخدم الحالية.
- تحديث `head()` للصفحة بحيث يعكس الوصف تقارير الحضور أيضاً.
