# وحدة طلبات ونماذج الموارد البشرية

وحدة موحّدة يقدّم عبرها الموظف أي طلب إداري (صيانة، مهمة ميدانية، شكوى، مقترح…) ويتابع مساره حتى الاعتماد، مع لوحة خاصة للموارد البشرية.

## كيف ستعمل

- صفحة جديدة **«الطلبات والنماذج»** في القائمة الجانبية ضمن مجموعة «العمل اليومي».
- تبويبات: **طلباتي** / **الطلبات الواردة إليّ** (للمدير والموارد البشرية) / **أنواع الطلبات** (إعداد — للموارد البشرية والمدير التنفيذي فقط).
- الموظف يضغط «طلب جديد» → يختار نوع الطلب → يظهر نموذج بحقول خاصة بذلك النوع → إرسال.
- مسار الاعتماد لكل نوع قابل للضبط: المدير المباشر ← الموارد البشرية ← (اختيارياً) المدير التنفيذي، بنفس منطق الإجازات الحالي.
- كل طلب يظهر تلقائياً في **مركز الموافقات** الحالي (الصفحة والنافذة المنبثقة والعدّاد) كنوع خامس بجانب الإجازات والتقييم والمهام وتصحيح الحضور.
- إشعار داخل النظام + بريد (حسب تفضيلات المستخدم) عند: وصول طلب جديد، اعتماده، رفضه، أو إعادته للتعديل.
- طباعة/تصدير الطلب المعتمد إلى PDF/Word بنفس نمط التقارير الحالي (مع الشعار وبيانات المؤسسة).

## كتالوج الطلبات (تُنشأ جاهزة عند التفعيل)

| المجموعة | الطلبات |
|---|---|
| الخدمات والتشغيل | طلب صيانة، طلب لوازم مكتبية، طلب عهدة/جهاز، طلب تسليم عهدة، طلب سيارة/مواصلات، طلب طباعة أو تصميم، طلب دعم تقني |
| العمل الميداني | طلب مهمة خارجية ميدانية، طلب سفر ومبيت، طلب تغطية نشاط، طلب سلفة سفر |
| شؤون الموظفين | طلب شهادة تعريف/راتب، طلب تعديل بيانات شخصية، طلب نقل بين إدارة أو قسم، طلب تغيير مسمى وظيفي، طلب تجديد عقد، طلب استقالة، طلب إخلاء طرف |
| المالية | طلب سلفة، طلب مكافأة/بدل، طلب صرف مصروفات نثرية، اعتراض على الراتب |
| التطوير والتدريب | طلب دورة تدريبية، طلب حضور مؤتمر/ورشة، طلب إجازة دراسية |
| الجودة والسلوك | شكوى إدارية، شكوى تظلّم، مقترح تحسين، بلاغ مخالفة، طلب اجتماع مع الإدارة |
| متفرقات | طلب عام (نموذج حر بعنوان ووصف ومرفق) |

الموارد البشرية تستطيع لاحقاً إضافة أو تعطيل أي نوع وتعديل حقوله ومساره من تبويب «أنواع الطلبات» دون الحاجة لتعديل برمجي.

## النماذج الديناميكية

كل نوع طلب يحمل تعريف حقوله (نص، نص طويل، رقم، تاريخ، وقت، قائمة اختيار، نعم/لا، مرفق). أمثلة:

- **صيانة**: الموقع، نوع العطل (كهرباء/سباكة/أثاث/تكييف/شبكة)، درجة الأولوية، الوصف، صورة.
- **مهمة ميدانية**: الجهة/الموقع، تاريخ ووقت الانطلاق والعودة، الغرض، وسيلة النقل، هل تحتاج بدل مواصلات.
- **شكوى**: نوع الشكوى، الجهة المشكو منها (اختياري)، التفاصيل، مرفق، خيار «سرّية للموارد البشرية فقط».
- **مقترح**: عنوان المقترح، المجال، الوصف، الأثر المتوقع.

الحقول السرّية لا تظهر للمدير المباشر عندما يُفعّل النوع خيار السرّية، ويتحوّل مساره مباشرة للموارد البشرية.

## تفاصيل تقنية

- **قاعدة البيانات** (مع GRANT وسياسات RLS على نمط `leave_requests`):
  - `hr_request_types`: الكود، الاسم، المجموعة، الأيقونة، `fields` (JSONB لتعريف الحقول)، `approval_flow` (مصفوفة مراحل)، `is_confidential`، `active`، `sort_order`.
  - `hr_requests`: `employee_id`، `type_id`، `title`، `values` (JSONB لإجابات الحقول)، `attachment_url`، `stage` (نوع `approval_stage` الحالي)، `return_reason`، حقول الاعتماد الثلاثة (`manager/hr/director`)، `created_by`، الطوابع الزمنية.
  - `hr_request_approvals`: سجل القرارات (مطابق لـ `leave_approvals`).
  - ترحيل يُدرج أنواع الطلبات في الجدول أعلاه بحقولها ومساراتها.
  - إعادة استخدام دالة `private.notify_*` / `notifyInApp` للإشعارات.
- **الخادم**: `src/lib/hr-requests.server.ts` + `src/lib/hr-requests.functions.ts` (`listMyRequests`, `listRequestTypes`, `saveRequest`, `submitRequest`, `deleteRequest`, `decideRequest`, `saveRequestType`) مع تحقق الصلاحية والمرحلة على الخادم.
- **مركز الموافقات**: إضافة `hr_request` إلى `ApprovalKind` في `src/lib/approvals.ts`، وقراءة الطلبات المعلّقة داخل `listPending` في `src/lib/approvals.server.ts`، وربط القرار في `useApprovals.ts`.
- **الواجهة**: `src/routes/_authenticated/requests.tsx` + `src/components/requests/` (`RequestTypePicker`, `DynamicRequestForm`, `RequestsList`, `RequestCard`, `RequestTypesAdmin`)، مع دعم RTL وتصميم بطاقات للموبايل ومكوّني `EmptyState`/`LoadingState` الحاليين.
- إضافة عنصر «الطلبات والنماذج» في `src/components/AppSidebar.tsx`.
