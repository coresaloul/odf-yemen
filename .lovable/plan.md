# استكمال منظومة الإدارات والأقسام والموظفين والمستخدمين والأدوار

الهدف: جعل هذه الوحدات الأربع متكاملة ومترابطة، مع تغطية كل العمليات (إضافة/تعديل/نقل/أرشفة/حذف آمن) وربطها ببعضها بشكل احترافي.

## 1. الإدارات والأقسام (المخطط التنظيمي)

الوضع الحالي: إضافة وحذف فقط، بدون تعديل، وبدون حماية عند وجود موظفين تابعين.

- إضافة **تعديل** لكل إدارة وقسم (الاسم، الوصف، المدير، الإدارة الأم للقسم).
- **حذف آمن**: منع الحذف إذا كان هناك أقسام أو موظفون تابعون، مع رسالة توضح العدد واقتراح النقل أولاً.
- **نقل قسم** بين الإدارات، و**نقل موظفين** جماعياً بين الإدارات/الأقسام.
- بطاقة إحصاءات لكل وحدة: عدد الأقسام، عدد الموظفين، المهام المفتوحة، متوسط الإنجاز.
- شجرة تنظيمية قابلة للطي/التوسيع مع بحث، وعرض المدير المباشر لكل مستوى.
- تصدير المخطط التنظيمي إلى Word/PDF عبر نفس آلية التقارير الحالية.
- الصلاحية: المدير التنفيذي والموارد البشرية يديران الهيكل؛ المدير المباشر يقرأ فقط.

## 2. الموظفون

- ربط إجباري واضح بين الموظف والإدارة/القسم/المدير المباشر مع منع الحلقات (موظف مديراً لنفسه أو دائرة إشراف).
- **دورة حياة الموظف**: على رأس العمل / إجازة / منتهي الخدمة، مع تعطيل حساب المستخدم تلقائياً عند إنهاء الخدمة، وإعادة تعيين مهامه المفتوحة.
- بطاقة ملف الموظف الكاملة (بيانات، وثائق، مهام، دوام، تقييمات) في مكان واحد.
- عمليات جماعية: نقل، تغيير الحالة، إنشاء حسابات.
- بحث وفلاتر: الإدارة، القسم، الحالة، نوع العقد، المدير المباشر، وثائق قاربت على الانتهاء.
- تصدير سجل الموظفين إلى Word/PDF.

## 3. المستخدمون والأدوار

- شاشة المستخدمين: بحث، فلترة بالدور/الحالة، ترقيم صفحات، وربط/فك ربط المستخدم بسجل موظف مباشرة من الشاشة.
- زر **دعوة مستخدم جديد** (إنشاء حساب + تحديد الدور + ربطه بموظف).
- **حذف/تعطيل** الحساب مع الاحتفاظ بسجل الموظف.
- ضمانات: لا يمكن إزالة آخر مدير تنفيذي في النظام، ولا يمكن للمستخدم تعديل دور نفسه.
- **مصفوفة صلاحيات** مرجعية داخل الشاشة توضح ما يستطيعه كل دور.

## 4. الترابط والصلاحيات (المعايير)

- توحيد قواعد الوصول في طبقة واحدة على الخادم: كل عملية إدارية تمر بتحقق دور فعلي (وليس تحققاً في الواجهة فقط).
- الأدوار: المدير التنفيذي (الكل) — الموارد البشرية (الهيكل والموظفون والمستخدمون بلا منح أدوار) — المدير المباشر (وحدته فقط) — الموظف (بياناته فقط).
- **سجل تدقيق (Audit Log)**: تسجيل كل عملية إنشاء/تعديل/حذف/تغيير دور مع المنفّذ والوقت، وعرضه في شاشة المستخدمين.
